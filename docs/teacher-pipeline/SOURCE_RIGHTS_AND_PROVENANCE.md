# Source Rights and Provenance

Processing requires a complete authorization record with verified/authorized status, processing permission, source checksum, permission source/version/date, classification, and retention policy. Missing or unsafe fields fail closed before teacher work.

Teacher results retain provider/model/endpoint/account/owner/quota domain, role, contract/prompt versions, request/attempt/reservation IDs, source/region/input/output hashes, raw-output retention status, latency, token/cost estimates, mock/live marker, creation time, and decision lineage.

Broad logs and status responses contain hashes and summaries, not full private page text, images, Base64 data, raw provider responses, authorization headers, or credential values.
