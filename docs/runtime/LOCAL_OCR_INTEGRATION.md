# تكامل OCR المحلي أثناء التشغيل

يمر كل PDF أولاً عبر محلل الصفحة، ثم بوابة ثقة النص الرقمي، ثم محرك قرار الصفحة. لا يُسمح بالاستخراج المباشر لمجرد وجود نص مضمّن، ولا يستبدل OCR النص الرقمي بصمت. الصفحة الممسوحة تبقى `pending_ocr_model` عندما يكون `CLOUDA_LOCAL_OCR_ENABLED=false`.

يُحسب SHA-256 للملف مرة واحدة ويُعاد استخدامه لكل الصفحات. بعد الاستخراج المباشر يُفحص ملخص النص مرة أخرى مقابل سياق الثقة؛ أي اختلاف يتحول إلى `review_required` مع مسار `manual_review` وعنصر ظاهر يحفظ حد الصفحة، من دون إخراج النص غير الموثوق. كما أن قصر النص وحده لا يكفي لتصنيف الصفحة `near_blank`؛ يلزم دليل بنيوي أو مرئي.

عند التفعيل:

1. تُصيّر الصفحة ضمن الحدود.
2. يُستدعى المحول المحدد.
3. يرفض النص الفارغ.
4. تسجل الهوية والمراجعة والزمن وأدلة التشخيص الداخلية.
5. يحافظ على ترتيب الصفحات وعلى RTL في DOCX.
6. تتحول الحالات غير الموثوقة أو غير المؤكدة أو الفشل إلى `review_required` ومسار `manual_review`.

الاختبارات تستخدم mock فقط. لم يُحدّد نموذج OCR نهائي أو أسلوب تدريب نهائي، والنماذج الحقيقية لا تعمل إلا بإعداد صريح لمسار محلي موثوق. واجهات المستخدم تعرض حالات وسبب القرار فقط، ولا تعرض نسب دقة أو ثقة أو جودة غير مقاسة.
